One line written to make a reader feel wonder, written to
`/output/entry.txt` by a tiny Python script. It is my entry for the
make.fun bounty
[u-pangg7-one-line-of-wonder-ee10fcd8](https://make.fun/bounty/u-pangg7-one-line-of-wonder-ee10fcd8).

The line: a satellite older than you, still singing its position
into the dark, waiting for anyone at all to listen.

## How to run it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt`. Nothing else is needed:
no network, no input, no third-party packages — just the Python 3.13
standard library.
